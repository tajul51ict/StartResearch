1. Scientific Machine Learning (SciML)

Scientific Machine Learning combines scientific knowledge, mathematical models, and machine learning to solve scientific problems.

Example: Predicting the temperature of a physical system using experimental data and mathematical equations.

2. Image Classification

Image classification is a task where a machine learning model identifies the category of an image.

Example: A model receives an image of a cat and predicts that the image belongs to the "Cat" class.

3. Neural Networks

Neural networks are computational models made of interconnected neurons arranged in layers. They learn patterns by adjusting weights and biases.

Example: A neural network can learn to recognize handwritten digits such as 0, 1, 2, or 9.

4. Calculus

Calculus studies changes in quantities. Derivatives help machine learning models understand how changing a parameter affects the output.

Example: If the loss function is (L(x)=x^2), its derivative is (L'(x)=2x). At (x=3), the gradient is 6.

5. Probability

Probability measures the likelihood of an event occurring.

Example: When tossing a fair coin, the probability of getting Heads is 1/2 or 50%.

6. Linear Algebra

Linear Algebra deals with vectors, matrices, and mathematical operations between them.

Example: A vector such as ([2,3]) represents a point or direction in a two-dimensional space.

7. Activation Function

An activation function introduces non-linearity into a neural network, allowing it to learn complex patterns.

Example: The ReLU function is defined as (f(x)=\max(0,x)). If the input is -3, the output is 0; if the input is 5, the output is 5.

8. Linear Transformation

A linear transformation changes a vector using a mathematical operation while preserving vector addition and scalar multiplication.

Example: Multiplying a vector by a matrix can rotate, scale, or reflect the vector.

9. Two-Dimensional Space

Two-dimensional space represents points using two coordinates: x and y.

Example: The point (3, 2) represents a position 3 units along the x-axis and 2 units along the y-axis.

10. Three-Dimensional Space

Three-dimensional space represents points using three coordinates: x, y, and z.

Example: The point (2, 3, 4) represents a position in 3D space.

11. Matrix Multiplication

Matrix multiplication combines matrices using rows and columns.


12. Statistics

Statistics helps us analyze, summarize, and understand data.

Example: Calculating the mean of the numbers 2, 4, 6, and 8 gives 5.

13. Softmax Function

Softmax converts numerical values into probabilities, where all probabilities sum to 1.

Example: A classification model may produce the following probabilities:

Cat: 0.70

Dog: 0.20

Bird: 0.10

The model predicts Cat because it has the highest probability.

14. Introduction to Transformations

Transformations change the position, orientation, size, or shape of an object.

Example: Moving a point from (2, 3) to (5, 3) is a translation.

15. Linearity Criteria

A transformation is linear if it satisfies additivity and homogeneity.

Example: If (T(x)=2x), then (T(3+4)=14), and (T(3)+T(4)=6+8=14). Therefore, it satisfies additivity.

16. Number Transformation

Number transformation changes numerical values from one form or range to another.

17. Transformation Examples

Different transformations can change the position or appearance of geometric objects.

Example: Scaling a point (2, 3) by a factor of 2 gives (4, 6).

18. Introduction to 3D Concepts

3D concepts involve points, vectors, axes, planes, and objects in three-dimensional space.

Example: A cube can be represented using vertices with x, y, and z coordinates.

19. Linear Transformation in 2D

A 2D linear transformation uses a 2×2 matrix to transform a vector.

20. Linear Transformation in 3D

A 3D linear transformation uses a 3×3 matrix to transform a vector in three-dimensional space.

Example: Scaling a vector (1, 2, 3) by 2 gives (2, 4, 6).

21. Numerical 3D Transformation

Numerical 3D transformation involves calculating the new coordinates of a point using matrices.

Example: Applying a scaling matrix to the point (1, 2, 3) can transform it into (2, 4, 6).

22. Composite Transformation

Composite transformation combines multiple transformations into one operation.

Example: An object can first be rotated and then scaled. Both transformations can be represented by matrices and combined through matrix multiplication.

23. Rotation and Shear Order

The order of transformations affects the final result because matrix multiplication is not generally commutative.

Example: Rotating a point first and then applying shear may produce a different result from applying shear first and then rotating.

24. Rotation Transformation

Rotation changes the orientation of a point or object around a fixed origin or axis.

Example: Rotating the point (1, 0) by 90° counterclockwise around the origin gives (0, 1).

25. Shear Transformation

Shear changes the shape of an object by shifting coordinates in proportion to another coordinate.

Example: A point (2, 3) under an x-direction shear with shear factor 1 becomes (5, 3).

26. Tracking Vector

A tracking vector represents or tracks the position, direction, or movement of a point or object.

Example: If an object moves from position (1, 2) to (4, 6), its displacement vector is (3, 4).
